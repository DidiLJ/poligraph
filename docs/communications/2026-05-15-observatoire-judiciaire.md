## Note de scope

Sub-plan A est un chantier de pipeline (extraction presse, refonte du registre, dashboard admin de santé des syncs). Aucune feature directement visible côté utilisateur. **Pas de post réseaux** : un message "amélioration backend" ne porte pas d'engagement civique tangible.

En revanche, le travail mérite une mention dans les canaux donateurs (Tipeee, HelloAsso) pour expliquer où va leur soutien.

## Tipeee : page projet Poligraph

**Titre :** Les coulisses du Q3, ce que change la nouvelle pipeline d'affaires

Poligraph publie des données. Ces données ne sortent pas de nulle part. Elles transitent par une pipeline qui ingère la presse, croise les sources, déduplique, classifie, et présente uniquement ce qui est sourcé et vérifié.

Ce trimestre, on a refondu cette pipeline. Le registre interne des syncs a été remis à plat (5 issues GitHub ouvertes et adressées), la phase de découverte d'affaires a été corrigée d'un bug de pagination qui faisait silencieusement perdre des cas, et un dashboard d'audit interne a été monté pour qu'on voie immédiatement si une source tombe en panne.

Concrètement, l'objectif de la séquence est de passer de 341 affaires documentées à 600 d'ici fin Q3. Le travail visible (les fiches) repose sur ce travail invisible (la pipeline). Votre soutien finance cette infrastructure.

https://fr.tipeee.com/poligraph

## HelloAsso : page asso Sankofa

**Titre :** Refonte pipeline judiciaire : où va votre soutien

L'association Sankofa porte Poligraph depuis 2024. Une grande partie du budget passe dans l'infrastructure technique, invisible mais critique : sans une pipeline de données fiable, l'observatoire ne peut pas tenir sa promesse de transparence.

Le sprint Q3 a refondu cette pipeline. Découverte d'affaires plus robuste, registre des syncs nettoyé, dashboard interne d'audit, automatisation des tests E2E quotidiens qui ouvrent une issue GitHub dès qu'un cron échoue. Ce sont des chantiers de fond qui éliminent toute une catégorie de bugs silencieux.

L'objectif chiffré : passer de 341 affaires documentées à 600 d'ici fin Q3, en s'appuyant sur la nouvelle pipeline de découverte.

Soutenir Sankofa : https://www.helloasso.com/associations/association-sankofa/formulaires/1
