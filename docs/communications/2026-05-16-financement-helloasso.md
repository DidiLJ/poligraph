## Tipeee : page projet Poligraph

**Titre :** Nouvelle plateforme principale de soutien

Petit changement à signaler aux abonnés Tipeee. La page /soutenir de Poligraph met désormais en avant HelloAsso (compte de l'association Sankofa qui porte le projet) comme plateforme principale, avec Tipeee gardé en option secondaire.

Pourquoi ce basculement. HelloAsso prélève 0 % sur les dons, l'argent va intégralement à Sankofa. Surtout, l'association a déposé une demande de rescrit fiscal qui ouvrira, dès validation, un reçu fiscal pour 66 % de déductibilité sur l'impôt. Le rescrit est en cours d'instruction côté fiscale, l'antériorité d'un don sur HelloAsso comptera rétroactivement.

Tipeee reste fonctionnel, votre abonnement actuel n'est pas affecté. Si vous voulez basculer sur HelloAsso pour bénéficier du futur reçu fiscal, c'est sur https://www.helloasso.com/associations/association-sankofa/formulaires/1 (sélectionnez la campagne Poligraph). Merci pour votre soutien continu.

https://fr.tipeee.com/poligraph

## HelloAsso : page asso Sankofa

**Titre :** Soutenir Sankofa, soutenir Poligraph

L'association Sankofa, qui porte l'observatoire civique Poligraph, a refondu sa page de soutien. HelloAsso est désormais la plateforme principale recommandée, pour trois raisons.

Premièrement, 0 % de frais. Tout votre don part à l'association. Deuxièmement, la possibilité de mettre en place un soutien récurrent qui sécurise le budget mensuel. Troisièmement, et c'est le point décisif : une demande de rescrit fiscal est en cours d'instruction. Une fois validée, elle ouvrira un reçu fiscal pour 66 % de déductibilité, applicable rétroactivement aux dons antérieurs.

Les fonds financent l'infrastructure technique de Poligraph (serveurs, base de données, hébergement), les outils éditoriaux (Anthropic API pour l'aide à la classification, jamais à la rédaction), et les enquêtes documentées sur les affaires politico-judiciaires.

Soutenir Sankofa : https://www.helloasso.com/associations/association-sankofa/formulaires/1
