## Tipeee : page projet Poligraph

**Titre :** Poligraph installable sur mobile

Bonne nouvelle pour qui consulte Poligraph en déplacement. Le site est désormais installable comme une application sur Android et iOS, sans passer par un store.

Concrètement, une fois installé, Poligraph apparaît sur l'écran d'accueil avec son icône, se lance en plein écran, et garde en mémoire les fiches que vous avez consultées récemment (politiciens et affaires) pour les rendre accessibles hors-ligne. Le tout sans tracker, sans store, sans pub.

L'installation est proposée automatiquement sur mobile après 3 visites, ou manuellement via le menu du navigateur (« Ajouter à l'écran d'accueil » sur iOS Safari, « Installer l'app » sur Chrome Android).

Pas de notifications push pour le moment. Une application native Expo est prévue pour Q4 avec cette fonctionnalité.

Ce chantier fait partie de l'objectif Q3 2026 d'installabilité mobile. Merci de soutenir Poligraph.

https://fr.tipeee.com/poligraph

## HelloAsso : page asso Sankofa

**Titre :** Poligraph s'installe sur votre téléphone

L'observatoire civique Poligraph, porté par l'association Sankofa, est désormais installable comme application sur Android et iOS, sans passer par un store.

Une fois installé, le site apparaît sur l'écran d'accueil et fonctionne hors-ligne pour les fiches consultées récemment. Pratique pour suivre un débat parlementaire dans les transports ou retrouver le dossier judiciaire d'un élu sans connexion.

L'installation est proposée automatiquement sur mobile après quelques visites, ou manuellement via le menu du navigateur. Pas de tracker, pas de pub, pas de magasin d'applications imposé.

Cette livraison ouvre une nouvelle voie d'accès à la donnée civique. Soutenir Sankofa : https://www.helloasso.com/associations/association-sankofa/formulaires/1
